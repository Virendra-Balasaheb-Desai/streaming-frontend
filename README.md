# Video Streaming Frontend

Frontend for a **video platform (similar to YouTube)** built using **React**.
It provides the user interface for browsing videos, viewing details, posting comments, and interacting with the backend APIs.

## Tech Stack

- React
- JavaScript
- Tailwind
- React Router for navigation

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/Virendra-Balasaheb-Desai/streaming-ui.git
cd streaming-ui
```

### 2. Install dependencies

```
npm install
```

### 3. Satisfy environment variables

Create a `.env` file using `.env.example`.

### 4. Run the server

```
npm run dev
```

The app will run on:

```
http://localhost:5147
```
